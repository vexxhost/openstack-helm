# OpenStack-Helm charts for Atmosphere 2026.1

This branch holds the OpenStack-Helm charts that Atmosphere `stable/2026.1` ships, imported from [vexxhost/atmosphere@a45d84796658](https://github.com/vexxhost/atmosphere/tree/a45d84796658debd75ef4357613f38195a259d8b) and kept as `UPSTREAM: <carry>:` commits on top of the pristine upstream charts (tag `import/2026.1`).

Charts are published to `oci://ghcr.io/vexxhost/openstack-helm/<chart>` by the publish workflow on `master`. See `docs/forks.md` in `vexxhost/images` for how fork branches are managed.
